## Cross-cutting DANGEROUS / DUPLICATE summary

- **dangerous — unguarded route:** `server/routes/simulation.ts` `GET /cultural-twin` is registered with `async` handler and no `requireAuth`/`requireAdmin` (file imports guards but doesn't apply them here). Verify intended public exposure + rate limiting.
- **dangerous — raw-SQL concentration:** `server/routes/analytics.ts` (7), `server/storage/product-storage.ts` (9), `server/services/ai-dashboard.ts` (8), `server/storage/loyalty-storage.ts` (6). These use drizzle's `sql\`\`` helper (sanctioned) but the volume warrants a parameterization/injection audit.
- **No hardcoded secrets found** in `server/` (secret-grep returned only an alphabet constant in `invoice-storage.ts` and an MCP tool-name string). All API-key matches resolve to `process.env` reads. GOOD.
- **duplicated:** `app/not-found.tsx` vs `pages/404.tsx`; `temperature-guide.tsx` vs `guides-temperature-guide.tsx`; the entire `components/reviews/` subsystem vs `components/products/product-reviews.tsx`.
- **merge candidates:** `lib/{cloudinary,image-utils,image-variants}.ts`; `server/utils/{auth,auth-helpers}.ts`; 3 variant selectors; 3 cross-sell widgets.
- **unused (barrel-only / zero importers):** `lib/mock-data.ts`, `components/search/{search-dialog, product-filters-advanced, search-autocomplete, index}.ts(x)`, `components/reviews/index.ts`, `components/recommendations/index.ts`, `components/blog/index.ts`, `server/services/claude-client.ts`, `server/scripts/debug-chat.ts`.

> All "unused"/"delete-candidate" findings need a final owner confirmation before `git rm` — barrels may be intended public API surface kept deliberately. None are wired into the build.
