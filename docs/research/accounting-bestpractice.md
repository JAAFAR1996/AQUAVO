## Highest-impact takeaways for AQUAVO's accounting design

1. **Cost snapshot = landed cost, frozen at sale.** Store per-SKU landed unit cost (supplier invoice + allocated import freight + duty, converted to IQD at the purchase-date FX rate). Freeze it onto each order line so historical margins never drift (A1, A5, A6, B2).
2. **Weighted-average costing.** Simplest IAS-2-compliant formula for a restocking trader with variable USD purchase prices; never LIFO (A2).
3. **Report contribution margin per order, not gross margin.** Deduct outbound shipping, courier/COD fees, discounts, and expected return loss — otherwise per-order profit is overstated 30–50% (B1, A3).
4. **Model COD as a receivable by courier with explicit states** and a weekly reconciliation delta (dispatched → delivered → remitted → reconciled; plus refused/returned). This is where cash actually leaks (B3, B4).
5. **Money = integers + currency tag.** IQD in **whole dinars** (fils obsolete), USD in **cents**; store the FX rate as DECIMAL for auditability. Never floats (A7, A8).
6. **FX gain/loss to P&L, not into inventory.** Once the IQD landed cost is set at receipt, later USD-payment rate changes are P&L, not a cost restatement (A6).
