```

Please enhance this logo image with the following corrections:

1. BACKGROUND: Make the background 100% transparent (pure alpha channel). Remove any white/off-white background, shadows, or artifacts around the logo edges. The logo should float cleanly on any surface.

2. COLOR CONSISTENCY: The icon (fish-infinity symbol) should be a consistent teal gradient from #0D7377 (darker teal) to #2DB5B9 (lighter teal). The text "AQUAVO" below/beside the icon should be EXACTLY #0D7377 (solid teal) — NOT navy, NOT dark blue. Both the icon and text must feel like they belong to the same color family.

3. EDGE QUALITY: Clean up any fuzzy or anti-aliased edges. The logo outlines should be crisp and sharp, as if vector-quality.

4. OUTPUT: High resolution, minimum 3000x3000px, PNG format with transparency.

Do NOT change the logo design, shape, or proportions. Only fix the colors, background, and edge quality.
```
