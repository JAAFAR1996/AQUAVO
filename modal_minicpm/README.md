# 🤖 MiniCPM-o 4.5 على Modal

تشغيل نموذج MiniCPM-o 4.5 على Modal بسهولة!

## ⚡ التثبيت السريع

```bash
# 1. تثبيت Modal CLI
pip install modal

# 2. تسجيل الدخول
modal setup

# 3. تشغيل النموذج
modal run minicpm_modal.py
```

## 🎯 الاستخدام

### تشغيل التجربة الأساسية
```bash
modal run minicpm_modal.py
```

### نشر API
```bash
modal deploy minicpm_modal.py
```

بعد النشر ستحصل على رابط API يمكنك استخدامه:
```bash
curl -X POST https://YOUR-URL.modal.run/chat_api \
  -H "Content-Type: application/json" \
  -d '{"message": "مرحبا!"}'
```

## 💰 التكلفة التقريبية

- **GPU A10G:** ~$1.10/ساعة
- **أول تشغيل:** ~5-10 دقائق (تحميل النموذج)
- **التشغيلات التالية:** سريعة جداً (النموذج مخزن)

## 🔧 تخصيص

عدّل `minicpm_modal.py` حسب احتياجاتك:

```python
# تغيير نوع GPU
gpu="A100"  # أقوى لكن أغلى

# تغيير timeout
timeout=1200  # مدة أطول
```
