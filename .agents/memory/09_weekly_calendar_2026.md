## القواعد الخمس قبل البناء

### 1. قاعدة الـ 80/20
- 80% قيمة: تعليم + ترفيه + قصص + خلف الكواليس
- 20% ترويج: منتج + عرض + CTA مباشر

### 2. قاعدة TOFU / MOFU / BOFU

| المرحلة | الهدف | النوع |
|---------|-------|-------|
| TOFU (وعي) | متابع جديد | ريل تعليمي / ترفيهي |
| MOFU (ثقة) | يقنع بالشراء | Carousel + UGC + behind scenes |
| BOFU (قرار) | يشتري | ريل ترويجي + Story + DM CTA |

النسبة الأمثل أسبوعياً: **3 TOFU + 2 MOFU + 1 BOFU**

### 3. قاعدة السلسلة (Series)
الخوارزمية 2026 تكافئ الـ repeat viewers.
"الجزء 1" يخلق انتظار + profile visits = follow.

### 4. قاعدة CTA الصح 2026

| الموقع بالقمع | CTA الأفضل |
|--------------|------------|
| TOFU | "احفظ هذا" أو "دزّه لصاحبك" |
| MOFU | "اكتب [كلمة] بالتعليقات وأرسلك [دليل]" |
| BOFU | "واتساب" أو "الرابط بالبايو" |

"Comment to Get" = أعلى conversion مقارنة بـ bio link وحده.

### 5. قاعدة Batch Creation
- يوم واحد بالأسبوع (الاثنين): تخطيط + تصوير + جدولة
- 80% محتوى دائم (Evergreen) مجدول مسبقاً
- 20% فراغ للتفاعل مع الأحداث اللحظية

## النموذج الأسبوعي الكامل

### الثلاثاء — TOFU: ريل تعليمي
**الوقت:** 19:00 بغداد

| | |
|--|--|
| Hook | رقم + مشكلة + جمهور محدد (5-8 كلمات) |
| CTA | "احفظ هذا" أو "دزّه لصاحبك اللي عنده حوض" |

مثال: "السر اللي ما يقوله محل الأسماك للمبتدئين"

### الأربعاء — MOFU: Carousel تعليمي
**الوقت:** 10:00 صباحاً

| | |
|--|--|
| النوع | Carousel 5-8 شرائح |
| الشريحة الأولى | Hook قوي (Loss Aversion أو Statistic) |

| Caption | "اكتب [كلمة] بالتعليقات وأرسلك النسخة الكاملة" |

مثال: "5 علامات تقول إن مي حوضك مسموم — احفظ قبل ما تنسى"

### الخميس — TOFU: ريل ترفيهي (DM Shares)
**الوقت:** 20:00 مساءً

| | |
|--|--|
| النوع | Reel 7-19 ثانية |
| الهدف | DM Shares = أقوى إشارة للخوارزمية |
| النص | "دزّه لصاحبك اللي [صفة]" |
| Story بعده | "أنت أي واحد؟ صوّت" + Poll |

مثال: "4 أنواع أصحاب الأحواض — أنت أي واحد؟ دزّه لصاحبك"

---

### الجمعة — BOFU: ريل ترويجي (value-first)
**الوقت:** 19:00 بغداد

| | |
|--|--|
| الهيكل | مشكلة (10 ثوانٍ) → حل (15 ثانية) → منتج (5 ثوانٍ) |
| Reciprocity | قبله بساعات: هدية مجانية بالـ Story |
| CTA | "الرابط بالبايو" أو "واتساب" |

مثال: "9 فحوصات بشريط واحد — هذا اللي يستخدمه المحترفون"

---

### السبت — MOFU: حوض الأسبوع (UGC)
**الوقت:** 10:00 صباحاً

حوض أحد المتابعين (بإذنه) + رأيك الخبير.
CTA: "أرسل صورة حوضك + نحكّمها المجان"

---

### الأحد — خلف الكواليس / إنساني
**الوقت:** 11:00 صباحاً

يوم في العمل / تغليف طلبيات / سؤال وجواب.
اللهجة: عراقي خالص، محادثة مباشرة.
