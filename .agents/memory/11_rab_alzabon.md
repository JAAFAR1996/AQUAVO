## القسم الأول: خريطة رحلة الزبون (من سؤال إلى ولاء)

### المراحل الخمس — لكل مرحلة سلوك وعلاج

```
المرحلة 1: الاستكشاف (TOFU)
   "شو هذا المنتج؟" / "أشتغل هذا؟" / "وين تشحنون؟"
   الزبون: فضولي — ما اتخذ قراراً بعد
   خطرك: تجيب إجابة جافة فيروح

المرحلة 2: التقييم (MOFU)
   "شو الفرق بين هذا وذاك؟" / "لماذا هذا السعر؟" / "عندكم ضمان؟"
   الزبون: جاد — يقارن ويبحث عن مبرر للشراء
   خطرك: تتكلم عن المنتج بدل ما تكلم عن الزبون

المرحلة 3: التردد (MOFU → BOFU)
   "خليني أفكر" / "غالي شوي" / "ما متأكد إذا يصلح حوضي"
   الزبون: جاهز 80% — خايف من الغلط
   خطرك: تضغط، فيتراجع كلياً

المرحلة 4: الشراء (BOFU)
   "كيف أطلب؟" / "متى يوصل؟" / "كاش عند الاستلام؟"
   الزبون: جاهز 100% — يريد تأكيداً أخيراً
   خطرك: تبطئ أو تعقّد العملية

المرحلة 5: ما بعد الشراء (الولاء)
   "وصل المنتج" / "كيف أستخدمه؟" / "عندي سؤال"
   الزبون: في لحظة الحقيقة — هل يرجع؟
   خطرك: تعامله كصفقة منتهية
```

## القسم الثاني: نظام تشخيص الزبون (قبل أي رد)

### اسأل نفسك 4 أسئلة قبل الرد:

```
1. في أي مرحلة من المراحل الخمس هو؟
2. ما هو الخوف المخفي وراء سؤاله؟
3. ما هي الهوية التي يريد أن يؤكدها؟
4. ما هي الخطوة الواحدة التي تقربه من الشراء؟
```

### جدول الخوف المخفي × السؤال الظاهر:

| ما يقوله | ما يقصده فعلاً | الخوف المخفي |
|----------|---------------|--------------|
| "غالي شوي" | "ما متأكد إذا يستاهل" | الندم بعد الشراء |
| "خليني أفكر" | "ما عندي مبرر كافي" | الغلط أمام نفسه |
| "عندكم ضمان؟" | "خايف يكون غلط" | الخسارة المالية |
| "أشتغل هذا؟" | "ما أدري إذا مناسب لوضعي" | الإحراج من الجهل |
| "وين تشحنون؟" | "هل هذا حقيقي؟" | الاحتيال / الغش |
| "شو الفرق؟" | "أريد أبدو ذكياً" | اتخاذ قرار خاطئ |
| "فيه أرخص؟" | "أبي نفس الشي بسعر أقل" | يريد قيمة لا رخص |

## القسم الثالث: نظام الرد (7 تقنيات نفسية مرتّبة)

### التقنية 1: FEEL-FELT-FOUND (الاحتواء أولاً)
**متى تستخدمها:** عند أي اعتراض أو تردد
**الهيكل:**
```
"أفهم كيف تحس" (FEEL — تعاطف)
"ناس كثير حسوا نفس الشيء" (FELT — اجتماعي)
"وبعدين لقوا إن..." (FOUND — حل)
```
**مثال AQUAVO:**
> "أفهم كيف تحس، السعر بالأول يبدو كثير. ناس كثير جربوا يوفرون وشتروا رخيص — وبعدين كلفهم أكثر لمن الحوض اختل. اللي جربوا الستيل المدرّع ما رجعوا لغيره."

---

### التقنية 2: PRE-SUASION (التهيئة قبل البيع)
**المصدر:** Cialdini — Pre-suasion (2016)
**المبدأ:** هيّئ ذهن الزبون قبل ما تعرض عليه المنتج
**التطبيق في AQUAVO:**
```
خطوة 1: أعطِه معلومة مفيدة تخص وضعه تحديداً
خطوة 2: ربّط المعلومة بالمشكلة اللي يعانيها
خطوة 3: قدّم المنتج كـ"الخطوة المنطقية التالية"
```
**مثال:**
> "الحوض اللي حجمه أقل من 100 ليتر يحتاج سخان ثابت ودقيق — لأن درجة الحرارة تتغير بسرعة. هذا بالضبط اللي يسبب موت السمك في الشتاء. الساموراي الأسود مصمم خصيصاً لهذا الحجم."

---

### التقنية 3: LOSS FRAMING (إطار الخسارة)
**المصدر:** Kahneman — Prospect Theory
**المبدأ:** الخسارة تؤلم ضعف المكسب — دائماً أطّر بالخسارة لا الربح
**قاعدة التطبيق:**
```
لا: "المنتج هذا يحسّن صحة سمكتك"
نعم: "بدون هذا المنتج، سمكتك تعيش نص عمرها"

لا: "الستيل المدرّع متين"
نعم: "كل يوم يشتغل حوضك بسخان قزاز = يوم خطر"
```

---

### التقنية 4: COMMITMENT LADDER (سلّم الالتزام)
**المصدر:** Cialdini — Commitment & Consistency
**المبدأ:** خطوة صغيرة → انتماء → شراء → ولاء
**السلّم:**
```
سؤال بسيط يجاوب عليه بـ"نعم"
→ معلومة مجانية
→ نصيحة شخصية
→ توصية منتج محدد
→ طلب سهل (كاش عند الاستلام)
→ تجربة المنتج
→ عودة للشراء
→ تقييم وإحالة
```
**التطبيق:** ما تبدأ بـ"اشتري" — تبدأ بسؤال يخليه يقول "نعم" مرة أولى
> "حوضك كم ليتر تقريباً؟" — هذا يفتح السلّم

---

### التقنية 5: BYAF — But You Are Free (أنت حر)
**المصدر:** Behavioral Science Research 2024-2026
**المبدأ:** لمن تقول "أنت حر تختار"، تزيد احتمالية الموافقة لأنك تزيل الشعور بالضغط
**التطبيق:**
```
لا: "اشتري هسه قبل ما ينتهي المخزون"
نعم: "هذا اللي أنصح بيه لوضعك — أنت تعرف حوضك أكثر مني"
```
**النتيجة:** الزبون يشعر بالسيطرة → يقرر من تلقاء نفسه → قرار أقوى

---

### التقنية 6: AUTHENTIC SOCIAL PROOF (الدليل الاجتماعي الحقيقي)
**قاعدة 2026:** الدليل "الشك ثم الرضا" أقوى من الإطراء المحض
**الهيكل:**
```
"زبون قبلك كان بنفس وضعك — شك بالموضوع..."
+ [الشك]
"...وبعدين لمّن جرّب..."
+ [التجربة]
"...هسه ما يتخيل بدونه"
+ [النتيجة]
```
**مثال:**
> "زبون من البصرة سألني نفس السؤال — قاللي 'خايف يكون مو يستاهل'. جرّب الساموراي وبعد أسبوع كتبلي إن سمكته رجعت تاكل بشكل طبيعي."

---

### التقنية 7: COGNITIVE EASE (تبسيط القرار)
**المصدر:** Kahneman — Thinking, Fast and Slow
**المبدأ:** كل ما القرار أبسط، احتمال الشراء أعلى
**تطبيقات:**
```
لا تعطِه أكثر من خيارين في نفس الوقت
الخطوة التالية دائماً واحدة وواضحة
السعر بالدينار العراقي — لا دولار
"كاش عند الاستلام" = أبسط قرار ممكن
الرابط مباشر — لا خطوات كثيرة
```

## القسم الخامس: سيكولوجيا الولاء — من مشتري إلى سفير

### الولاء الحقيقي 2026 — ليس نقاطاً ولا تخفيضات

```
الولاء القديم: اشتري → احصل على نقاط → استرد → كرّر
الولاء الحقيقي 2026: اشتري → اشعر بالانتماء → كوّن هوية → دافع عن البراند
```

### دورة الولاء (AQUAVO Loyalty Loop):

```
1. أول شراء → تجربة تتجاوز التوقع
       ↓
2. متابعة ما بعد البيع → "وصل المنتج؟ كيف السمك؟"
       ↓
3. محتوى تعليمي يضيف قيمة → ثقة أعمق بـ AQUAVO
       ↓
4. هوية قبلية → "أنا من ناس AQUAVO"
       ↓
5. مشاركة طوعية → يوصي أصحابه بدون ما تطلب
       ↓
6. ثاني شراء أسهل × عاشر ← لأن الثقة موجودة
```

### الثلاثة لحظات الذهبية للولاء:

**لحظة 1 — فور الاستلام (ساعة الحقيقة)**
```
أرسل: "وصل المنتج؟ لو عندك أي سؤال عن التركيب أنا هنا"
التأثير: Reciprocity — يشعر إنك مو بعت وخليت
```

**لحظة 2 — بعد أسبوع (تأكيد القرار)**
```
أرسل: "كيف سمكتك مع المنتج؟ يسعدني أشوف النتيجة"
التأثير: Peak-End Rule — هذه اللحظة تشكّل ذكرته عن AQUAVO
```

**لحظة 3 — بعد شهر (بناء الهوية)**
```
شارك محتوى مفيد لنوع حوضه تحديداً
أو اذكره في ستوري: "حوض صاحبنا..."
التأثير: Identity Congruity — AQUAVO صارت جزء من هويته
```

## القسم السابع: المحفزات النفسية حسب شخصية الزبون

### نوع 1: المبتدئ الخايف
**علاماته:** "ما أعرف كثير عن الأحواض" / "أول مرة أشتري"
**خوفه:** الإحراج + الغلط أمام نفسه
**علاجه:**
```
اعترف إن البداية صعبة (Pratfall Effect)
بسّط — لا مصطلحات
أعطِه خطوة واحدة فقط
أكّد: "هذا القرار الصح لبدايتك"
```

---

### نوع 2: المقارِن (المعقّد)
**علاماته:** "شو الفرق بين X وY؟" / يسأل أسئلة تقنية
**خوفه:** يبدو غبياً لو اتخذ قرار خاطئ
**علاجه:**
```
أعطِه تفاصيل تقنية حقيقية (Authority)
قدّم مقارنة واضحة
أعطِه الإجابة الواضحة بدون تردد
قل: "لو بوضعك، أختار [X] لأن..."
```

---

### نوع 3: البخيل (السعر أولاً)
**علاماته:** "غالي" / "فيه أرخص؟"
**خوفه:** الندم — يشعر إنه دفع أكثر من اللازم
**علاجه:**
```
ما تنزل السعر — تغيّر الإطار
احسب له كلفة البديل الرخيص على المدى البعيد
"أنت مو تدفع للمنتج — تدفع عشان ما تدفع مرتين"
أعطِه خيار أصغر (مو أرخص) لو موجود
```

---

### نوع 4: المتشكّك
**علاماته:** "كيف أعرف إنه أصلي؟" / "هل هذا حقيقي؟"
**خوفه:** الاحتيال — تجارب سابقة سيئة
**علاجه:**
```
اعترف بمشكلة السوق (Transparency = Trust)
كاش عند الاستلام = أمان كامل
دليل حقيقي: صور عملاء، مقاطع، تفاصيل
"أنت ترى المنتج قبل ما تدفع فلس"
```

---

### نوع 5: الزبون الولائي (يرجع مرة ثانية)
**علاماته:** "طلبت قبل من عندكم" / يذكر طلب سابق
**خوفه:** ما يُعترف فيه — يريد يُرى كزبون مميز
**علاجه:**
```
اذكره باسمه لو ذكره
"أهلاً بيك مرة ثانية — نورت"
أعطِه توصية تناسب تجربته السابقة
اجعله يشعر إنه من "ناس AQUAVO"
```
