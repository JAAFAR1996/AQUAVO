# 🧠 Psychology Framework — Layer 6 Memory

## The 12 Core Principles (AQUAVO Marketing)

| # | Principle | Arabic Name | Application |
|---|-----------|-------------|-------------|
| 1 | Loss Aversion | الخوف من الخسارة | "بدون X = سمكتك تموت" |
| 2 | Social Proof | الإثبات الاجتماعي | "عشرة آلاف مربي في العراق" |
| 3 | Scarcity | الشح | "باقي 3 قطع بس" |
| 4 | Authority | السلطة | نبرة الخبير، مصطلحات تقنية |
| 5 | Curiosity Gap | فجوة الفضول | "الشي الوحيد اللي ينقص حوضك..." |
| 6 | Contrast Effect | تأثير التباين | قبل/بعد، مقارنة الجودة |
| 7 | Identity/Tribe | الهوية القبلية | "المربي الحقيقي يعرف الفرق" |
| 8 | Peak-End Rule | ذاكرة الذروة | نهاية قوية في كل محتوى |
| 9 | Anchoring | التثبيت | السعر الأعلى أولاً |
| 10 | Commitment | الالتزام | خطوة صغيرة → انتماء كامل |
| 11 | Reciprocity | المعاملة بالمثل | محتوى تعليمي مجاني |
| 12 | Status | الوضع الاجتماعي | "حوضك يعكس مستواك" |

## Tribal Marketing Framework (Us vs Them)

### الهيكل:
```
العدو المشترك:  → التهاون / المربي المبتدئ الكسول
الشيطنة:        → منتجات رخيصة تضر بالسمك
المنقذ:          → AQUAVO الخبير
الانتماء:        → نادي المربيين الحقيقيين
```

### جمل جاهزة للمحتوى:
- "مو كل من عنده حوض يعرف شلون يربي"
- "المربي الحقيقي يعرف الفرق بين الفلتر الحقيقي والتقليد"
- "حوضك مو بس ماء وسمك — هو بيئة كاملة تحتاج علم"
- "هؤلاء يشترون أرخص شي — إنت مو منهم"

## Content Psychology Scoring (1-10)

**Score 8+:** 2-3 principles active simultaneously  
**Score 9+:** Strong tribal hook + curiosity gap + loss aversion  
**Score 10:** All 3 above + perfect Baghdad dialect + brand compliance
