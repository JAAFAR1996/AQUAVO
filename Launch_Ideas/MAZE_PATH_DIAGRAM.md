# 🧩 تخطيط مسار المتاهة (Maze Path Blueprint)
## المسار الصحيح vs المسار الخاطئ

هذا هو التصميم الهندسي للمتاهة الذي يجب أن تتبعه السمكة في الفيديو.

### 🖼️ المخطط الهندسي (Top-Down View)

```
      Start
      [S]
       │
       ▼
    ┌──┴──┐
    │     │
    ▼     ▼
 [RIGHT] [LEFT/DOWN] 
  (Wrong) (Correct)
    │       │
    ▼       ▼
   [X]      │
 Dead End   │
  (Wall)    └──► [TURN RIGHT] ──► [TURN UP] ──► [E]
                                                End
                                               (Food)
```

### 📍 تفاصيل المسار خطوة بخطوة

| الخطوة | الموقع | الحركة | النتيجة |
|--------|--------|--------|---------|
| **1** | **[S] Start** | السمكة تدخل المتاهة | بداية التحدي |
| **2** | **التقاطع الأول** | السمكة تختار **اليمين** (خطأ) | ❌ خيار خاطئ |
| **3** | **[X] Dead End** | تصطدم بالحائط | 🛑 توقف وحزن |
| **4** | **الرجوع** | تعود للتقاطع | 🤔 تفكير (Freeze) |
| **5** | **التقاطع (محاولة 2)** | تختار **اليسار/الأسفل** (صح) | ✅ تذكرت! (Eureka) |
| **6** | **المسار الطويل** | تسبح بسرعة: أسفل ← يمين ← أعلى | 🚀 سرعة وثقة |
| **7** | **[E] End** | تصل للطعام | 🏆 فوز واحتفال |

### 📐 مقاييس الرسم (للـ AI Prompt)

عند طلب رسم المتاهة من الذكاء الاصطناعي، استخدم هذا الوصف:

> "A top-down diagram of a simple maze.
> Start point [S] at top-left.
> End point [E] at bottom-right.
> One obvious dead-end path [X] near the start.
> The correct path winds around the dead-end."

---
*هذا المخطط يضمن أن القصة (الخطأ ثم التصحيح) ممكنة منطقياً داخل المتاهة.*
