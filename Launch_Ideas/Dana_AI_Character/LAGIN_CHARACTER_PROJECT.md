## 1. 👤 هوية الشخصية (Character Identity)

### الاسم

**"لجين"** — اسم عراقي أصيل، يعني الفضة، ناعم على اللسان، لا يبدو تسويقياً، ويُحفظ بسرعة.

> **بدائل:** "ريم" للبساطة، أو "مياء" لارتباطه بالماء (مناسب لموضوع الأحواض)

### المظهر الجسدي

| العنصر | التفاصيل |
|--------|----------|
| **العمر** | 22-25 سنة — تبدو ناضجة لكن شابة |
| **البشرة** | عسلية قمحية (عراقية أصيلة) |
| **الشعر** | أسود داكن ناعم، طويل أو متوسط، طبيعي |
| **العيون** | بنية عسلية أو خضراء — حادة وذكية |
| **الملامح** | أنف صغير دقيق، شفاه ممتلئة، وجه بيضاوي |
| **الجسم** | قوام طبيعي، ليس مبالغاً، يبدو حقيقياً |
| **الملابس** | تي-شيرت AQUAVO أو هودي branded — casual professional |

### الشخصية

- تتكلم بالعراقي الحضري (بغدادي/بصراوي) — مفهوم لكل العرب
- ذكية، عملية، تشرح بأسلوب "صاحبتك اللي عندها معلومة"
- لا تبدو خبيرة متعجرفة — تبدو متحمسة للأحواض مثلك
- تبتسم بشكل طبيعي، تستخدم يديها عند الشرح

## 3. 🔄 سير عمل أول ريلز (Workflow)

```
1. Midjourney → صور الشخصية (4-6 صور ثابتة عالية الجودة)
2. Flux LoRA → تدريب النموذج (استثمار مرة واحدة)
3. Kling/Hailuo → تحريك الصورة (15-30 ثانية)
4. HeyGen → إضافة حركة الشفاه (للمرحلة الثانية)
5. CapCut → مونتاج + نصوص عربية + موسيقى
6. النشر على TikTok + Instagram Reels في نفس الوقت
```

## 5. 🎬 أول ريلز — الفكرة الكاملة

### العنوان: "ليش سمچتك ماتت؟ 😢"

**الهوك (الثانية 0-3):**
لجين تنظر للكاميرا بتعجب وتقول:
> "كل الناس يقولون أسماكهم ماتت — بس ما أحد يعرف السبب الحقيقي"

**الجسم (الثانية 3-25):**
تظهر 3 أسباب مع animations بسيطة:
1. "الكلور بالماء — تحتاج ترسّب 24 ساعة"
2. "صدمة الحرارة — فرق درجة 2 يكفي يقتل"
3. "حوض جديد = تسمم أمونيا — لازم تعالجه أسبوعين"

**النهاية (الثانية 25-35):**
> "كل هذا نبيعه وأكثر — رابط بالبايو"
> شعار AQUAVO يظهر بشكل أنيق
