## 📝 خطوات الإعداد (ManyChat):

### الخطوة 1: تحويل الحساب إلى Business
```
1. افتح Instagram → الإعدادات
2. الحساب → التبديل إلى حساب احترافي
3. اختر "منشئ محتوى" أو "نشاط تجاري"
4. أكمل البيانات المطلوبة
```

---

### الخطوة 2: ربط Instagram بصفحة Facebook
```
1. افتح Facebook → أنشئ صفحة جديدة (إذا لم يكن عندك)
2. في Instagram: الإعدادات → الحساب
3. اضغط "ربط صفحة Facebook"
4. اختر الصفحة وافق على الأذونات
```

---

### الخطوة 3: التسجيل في ManyChat
```
1. اذهب إلى: https://manychat.com
2. اضغط "Get Started Free"
3. سجل الدخول بحساب Facebook
4. وافق على الأذونات المطلوبة
```

---

### الخطوة 4: ربط Instagram بـ ManyChat
```
1. في لوحة ManyChat، اضغط "Settings" (أعلى اليمين)
2. اختر "Instagram"
3. اضغط "Connect Instagram Account"
4. اختر حساب Instagram المرتبط بصفحة Facebook
5. وافق على الأذونات (إدارة التعليقات والرسائل)
```

---

### الخطوة 5: إنشاء الأتمتة (Automation)

#### أ. إنشاء Trigger جديد:
```
1. من القائمة الجانبية: Automation → "+ New Automation"
2. اختر "Instagram Comments" كـ Trigger
3. اسم الأتمتة: "AQUAVO_First_50_Auto_Reply"
```

#### ب. تحديد Keywords:
```
Trigger Settings:
- اختر "Specific Words"
- أضف الكلمات المفتاحية:
  * "سمك"
  * "سمكة"
  * "بليكو"
  * "جولد فيش"
  * "بيتا"
  * "نيون"
  * "مولي"
  * "جوبي"
  * (أي أنواع سمك شائعة)
```

#### ج. إعداد الرد التلقائي:
```
Reply Action:
1. اضغط "+ Add Action"
2. اختر "Send Message"
3. اختر "Instagram DM" (رسالة خاصة)
4. اكتب الرسالة:
```

**نص الرسالة:**
```
مرحباً {{first_name}}! 🐟

شكراً على تعليقك عن سمكتك! 

هذا رابط الاشتراك الخاص فيك مع خصم 5%:
👇
https://aquavo.sa/early-access?code={{user_id}}

⏰ العرض لأول 50 شخص فقط!

AQUAVO - أحواض ذكية 🚀
```

### الخطوة 6: تحديد العدد (أول 50 فقط)

#### طريقة 1: عداد يدوي
```
1. في ManyChat → Custom Fields
2. أنشئ حقل: "counter" (نوع: Number)
3. في الـ Automation:
   - أضف Condition: IF counter < 50
   - THEN: Send Message + Increment counter
   - ELSE: Don't send (أو أرسل رسالة "العرض انتهى")
```

#### طريقة 2: تعطيل يدوي (أسهل)
```
- راقب العدد يدوياً
- بعد 50 تعليق، أوقف الـ Automation من لوحة ManyChat
```

---

### الخطوة 7: اختبار النظام
```
1. انشر الريلز
2. اطلب من صديق التعليق بـ "عندي سمك"
3. تأكد من وصول الرسالة التلقائية
4. تحقق من الرابط يعمل
```
