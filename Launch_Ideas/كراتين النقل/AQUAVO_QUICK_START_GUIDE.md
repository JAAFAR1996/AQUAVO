| **النوع** | أكورديون (طية زجزاج) — 4 طيات = 8 ألواح |

# 🎨 ملاحظات التصميم

## اللغة البصرية

| العنصر | المواصفة |
|--------|----------|
| **الألوان** | تيل #0D7377 (رئيسي) + كحلي #0A1F3B (نصوص) + أبيض (خلفية) |
| **الخط العربي** | خط واضح وكبير (مثل IBM Plex Arabic أو Cairo) — 12-14pt |
| **الأيقونات** | بسيطة خطية (line icons) بلون تيل — واضحة بنظرة واحدة |
| **الأرقام** | كبيرة وجريئة داخل دوائر تيل — يسهل تتبع الخطوات |
| **رسومات** | رسومات خطية بسيطة (حوض، سمكة، فلتر) — مو صور حقيقية |
| **المسافات** | مسافات بيضاء كافية — لا تزحم اللوح أبداً! |

## قواعد النص

| القاعدة | التفاصيل |
|---------|----------|
| **اللهجة** | عراقي عامي 100% — "حط" مو "ضع"، "شيل" مو "أزل" |
| **الجمل** | قصيرة جداً — 5-8 كلمات بالسطر |
| **الأفعال** | مباشرة: "اغسل"، "حط"، "صب"، "غيّر" |
| **الإيموجي** | بكل لوح 3-4 إيموجي — تسهل الفهم البصري |
| **التحذيرات** | ❌ و ⚠️ و 🔴 — واضحة وصريحة |

## ترتيب القراءة

```
يُقرأ من اليمين لليسار (عربي):

الغلاف → المكان → الغسل → المعدات → الماء → السمك → التغذية+الصيانة → تواصل

  [8]    [7]     [6]     [5]      [4]     [3]         [2]              [1]
  
  ← اتجاه الفتح
```
