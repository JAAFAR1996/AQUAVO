# 🐟 بطاقات توافق الأسماك — 3 متغيرات
## AQUAVO Fish Compatibility Cards — تصميم + محتوى + بروموتات

---

> **📊 مبني على أبحاث:**
> - نظام ألوان عالمي: 🟢 أخضر = متوافق | 🟡 أصفر = حذر | 🔴 أحمر = ممنوع
> - بيانات من Petco, AquariumConnection, Chewy, AquariumCoop (2025)
> - أكثر الأسماك شعبية في العراق: بيتا، جوبي، مولي، بلاتي، ذهبية، انجل، سيكلد
> - كل بطاقة = **دليل إنقاذ** يمنع الزبون من خسارة أسماكه

## 📐 المواصفات (مشتركة للثلاث)

| المواصفة | التفاصيل |
|----------|----------|
| **القياس** | 140×90mm (حجم بطاقة الائتمان — يخلّيها بمحفظته!) |
| **الخامة** | 350gsm مطفي Soft-Touch |
| **التشطيب (أمام)** | Spot UV على صورة السمكة الرئيسية + الشعار |
| **التشطيب (خلف)** | مطفي كامل مع طباعة ملونة |
| **الزوايا** | مدورة 3mm |
| **رمز التعريف** | كل بطاقة عليها رقم `1/3` `2/3` `3/3` — **يجمّعهم!** |

## 🎯 الفكرة

> **3 بطاقات × 3 أسماك بطلة = 9 توافقات مفصلة**
>
> كل بطاقة تركز على سمكة بطلة واحدة (الأكثر مبيعاً في العراق)
> وتوضح مع مَن تتوافق ❌✅ ومع مَن لا

### لماذا 3 بطاقات وليس واحدة؟
| السبب | الأثر النفسي |
|-------|-------------|
| **التجميع** | "عندي 1/3 — أبي الباقيات!" = طلب ثاني! |
| **القيمة المُدركة** | 3 بطاقات = موسوعة صغيرة — يحس إنه حصل شي قييم |
| **المشاركة** | يوري صديقه: "شوف هالبطاقات الحلوة!" = تسويق مجاني |
| **التنوع** | كل بطاقة بلون مختلف = مجموعة بصرية مُدمنة |
