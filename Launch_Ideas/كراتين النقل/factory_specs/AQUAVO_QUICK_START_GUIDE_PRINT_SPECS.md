## 5. طريقة الطي (Folding)

```
منظر من الأعلى (مفتوح):

│ لوح 8 │ لوح 7 │ لوح 6 │ لوح 5 │ لوح 4 │ لوح 3 │ لوح 2 │ لوح 1 │
│الخاتمة │الصيانة │السمك  │الماء  │المعدات│التجهيز│المكان │الغلاف │
│ ←←←←←  اتجاه القراءة من اليمين لليسار  ←←←←← │

منظر جانبي (مطوي):

   ┌──┐  ┌──┐  ┌──┐  ┌──┐
   │ 1│  │ 3│  │ 5│  │ 7│    ← الوجه الأمامي
   │  ├──┤  ├──┤  ├──┤  │
   └──┘  └──┘  └──┘  └──┘
         ↑ طية زجزاج (Z-Fold / Accordion)
```

| المواصفة | التفاصيل |
|----------|----------|
| **نوع الطي** | زجزاج (Accordion / Z-Fold) |
| **عدد الطيات** | 3 طيات |
| **اتجاه الطي** | اللوح 1 (الغلاف) يكون بالأعلى عند الطي |
| **خطوط الطي** | Score lines (خطوط ضغط) — مو قص |
| **مسافة خط الطي** | كل 87.5 مم |

> [!WARNING]
> تأكد أن خطوط الطي (Score) دقيقة — أي انحراف 1 مم يأثر على المنظر النهائي
