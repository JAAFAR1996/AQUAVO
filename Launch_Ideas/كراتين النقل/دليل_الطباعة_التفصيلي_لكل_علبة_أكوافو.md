## 🎁 داخل علبة الحوض — تجربة الكشف الدراماتيكية:

> **المبدأ:** 5 طبقات = 5 لحظات "واو!" = فيديو unboxing مثالي

```
الطبقة 1: الحزام الورقي الفاخر
    "مرحباً بيك بعائلة أكوافو — وصلت الممنوعات 😏"
    → أول انطباع = فخامة + حماس
         ↓
الطبقة 2: فتح الغطاء → الفلاب الداخلي
    "✨ حوضك يستاهل الأصلي! ✨"
    → الترقب يتصاعد!
         ↓
الطبقة 3: EPE الأبيض النظيف (أو EVA أسود للفاخر)
    اللوغو AQUAVO مكبوس بالحرارة على الفوم
    → "حتى الفلين بعلبتهم فاخر!" — انبهار
         ↓
الطبقة 4: كشف الحوض!
    الحوض يجلس بالتجويف المحفور بالضبط
    + حزام ورقي صغير يلف الحوض نفسه:
    "أنا حوضك الجديد — خذني للبيت! 🏠"
    → لحظة الكشف الكبيرة!
         ↓
الطبقة 5: تحت الحوض — المفاجآت!
    📋 دليل البداية السريعة (مطوي أنيق)
    🃏 بطاقة نصيحة عشوائية (#1-20)
    🪪 بطاقة التوافق (أي سمكة مع أي سمكة)
    🎁 هدية مفاجأة (عينة طعام أو بودرة بكتيريا)
    🎟️ بطاقة UGC + كود خصم للطلب القادم
    → "شوفوا كل هالأشياء اللي بالعلبة!" — محتوى ذهبي!
```

# ✅ القواعد النهائية — لازم تلتزم فيها!

1. **كل سطح = فرصة تسويقية** — ما في سطح فارغ بدون هدف
2. **كل نص بالعامي العراقي** — مو فصحى باردة أبداً
3. **الخط العربي أنيق** — مو خط آلي أو ترجمة گوگل
4. **الفلاب الداخلي = أقوى عنصر** — أول 3 ثواني بالفيديو
5. **القاع = Easter Egg** — محتوى مخفي يخلي الزبون يستكشف
6. **EVA أسود للمكعبات** — حوض فاتح على أسود = صورة تنتشر
7. **كود خصم مخفي** — يشاركه مع الأصدقاء = نمو عضوي
8. **مطفي مو لامع** — يتصوّر أحسن (بدون انعكاسات)
9. **حزام ورقي لكل علبة** — يبني الترقب + يحمي
10. **QR Code لكل قياس** — يوصل لمحتوى مخصص لهالمنتج
