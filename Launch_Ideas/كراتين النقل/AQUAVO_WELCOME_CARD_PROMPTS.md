# ⚙️ نصائح التوليد

| النصيحة | التفاصيل |
|---------|----------|
| **لا تكتب عربي** | AI يشوّه النص العربي — خلي البطاقة فارغة أو إنجليزي وغيّره بـ Canva |
| **أضف `--no text`** | بـ Midjourney عشان ما يحط نص مشوّه |
| **نسبة العرض** | استخدم `--ar 3:2` للبوستكارد أو `--ar 2:3` للعمودي |
| **Stylize منخفض** | `--s 50-75` للواقعية، `--s 200+` للفني |
| **كاميرا** | أضف "shot with 50mm lens, f/2.8" للواقعية |
| **الإضاءة** | "soft diffused natural light" أفضل من "studio light" للبطاقات |
| **الخلفية** | مرمر أبيض = فاخر، خشب = دافئ، خرسانة = حديث، تيل = AQUAVO |
| **عدة زوايا** | ولّد نفس البطاقة بزوايا مختلفة: overhead, 45-degree, close-up |
