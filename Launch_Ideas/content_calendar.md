## 🎬 نظام Batch (تصوير دفعة واحدة)

> **الفكرة:** صوّر 7-10 فيديوهات بيوم واحد بالأسبوع!

### يوم التصوير (السبت مثلاً):
```
الصباح (ساعتين):
├── تجهيز 5-7 أفكار من القائمة
├── تصوير كل الفيديوهات دفعة واحدة
└── غيّر الملابس بين كل 2-3 فيديوهات (يبان كأنه أيام مختلفة)

المساء (ساعة):
├── مونتاج سريع
├── إضافة النصوص والموسيقى
└── جدولة النشر للأسبوع كامل
```

## 🎁 Lead Magnet (يرفع التحويل 3x)

### ما هو؟
**PDF مجاني:** "دليل البدء بحوض السمك - 10 أخطاء لازم تتجنبها"

### المحتوى:
1. الخطأ #1: اختيار حوض صغير جداً
2. الخطأ #2: تخطي دورة النيتروجين
3. الخطأ #3: الإفراط بالتغذية
4. ... (10 أخطاء)
5. قائمة تسوق للمبتدئين ✅
6. جدول الأسبوع الأول

### كيف يشتغل:
```
فيديو/بوست → "حمّل الدليل المجاني!"
           → صفحة الانتظار
           → أدخل رقمك/إيميلك
           → تحصل على PDF + تنضم للقائمة
```

## 📺 Live أسبوعي (يبني ثقة سريعة)

### التوقيت:
**كل خميس 8:00م - 8:30م (توقيت بغداد)**

### الفورمات:
```
5 دقائق: ترحيب + "شنو جديد هالأسبوع"
15 دقيقة: أسئلة وأجوبة من المتابعين
5 دقائق: "تحديث البضاعة + الإطلاق"
5 دقائق: CTA "الرابط بالبايو للتسجيل!"
```

### نصائح:
- اطلب الأسئلة مسبقاً بالـ Stories
- سجّل اللايف وقطّعه clips للأسبوع الجاي

## 📋 صفحة الانتظار المثالية

### العناصر الأساسية:
```
1. عنوان قوي: "كن من أول 30 واحصل على خصم 20%!"
2. صورة/فيديو قصير (15 ثانية)
3. 3 فوائد فقط:
   ✅ خصم 20% على أول طلب
   ✅ أولوية الشراء قبل الجميع
   ✅ هدية مجانية مع الطلب
4. نموذج بسيط: رقم واتساب فقط
5. عداد الأماكن المتبقية (FOMO)
```

### CTA ثابت لكل فيديو:
```
"سجّل بقائمة الانتظار - الرابط بالبايو!"
```
