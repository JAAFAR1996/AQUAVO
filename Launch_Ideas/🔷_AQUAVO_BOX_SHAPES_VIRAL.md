## 🎯 **3 أشكال فريدة (جميلة + قابلة للتنفيذ):**

---

### **1️⃣ شكل السداسي (Hexagon) - "بيت النحل"** 🔷

```
الشكل:
┌─────┐
/       \
\       /
└─────┘

لماذا؟
- غريب! (مو مربع عادي)
- يقف بثبات
- زوايا = photogenic!
- يرمز للنظام البيئي (ecosystem)
```

#### **المقاسات الثلاثة:**

**صغير (S):**
```
القطر: 10 سم
الارتفاع: 8 سم
للمنتج: علب طعام، أدوية
التكلفة: 1,200 دينار
```

**متوسط (M):**
```
القطر: 18 سم
الارتفاع: 12 سم
للمنتج: فلاتر، إضاءة، مضخات
التكلفة: 2,000 دينار
```

**كبير (L):**
```
القطر: 35 سم
الارتفاع: 40 سم
للمنتج: أحواض، معدات كبيرة
التكلفة: 4,500 دينار
```

#### **لماذا الزبون راح يصور؟**
```
📸 اللحظة 1: يستلم الطرد
"شوفوا الشكل! سداسي!" 🔷

📸 اللحظة 2: يصوره من زوايا مختلفة
"هذا مو صندوق عادي!"

📸 اللحظة 3: يحطه جنب أشياءه
"يطلع حلو بالصورة!" ✨
```

#### **التنفيذ:**
- **اصنعه محلياً:** مصنع كرتون يقدر يسوي قالب سداسي (one-time cost: 200,000 د)
- **أو اطلبه online:** AliExpress/Alibaba (بالجملة أرخص)
- **طريقة DIY:** قص كرتون عادي بباترون سداسي

### **2️⃣ شكل الأسطوانة (Cylinder) - "أنبوب الاختبار"** 🧪

```
الشكل:
 ___
|   |
|   |
|   |
|___|

لماذا؟
- يبدو "علمي" (lab vibe)
- يلف = satisfying!
- مختلف تماماً عن الصناديق
- سهل الشحن (يتدحرج!)
```

#### **المقاسات الثلاثة:**

**صغير (S):**
```
القطر: 6 سم
الطول: 15 سم
للمنتج: علب طعام، أدوية صغيرة
التكلفة: 800 دينار
الإغلاق: غطاء بلاستيك شفاف
```

**متوسط (M):**
```
القطر: 10 سم
الطول: 30 سم
للمنتج: فلاتر، أدوات طويلة
التكلفة: 1,500 دينار
الإغلاق: غطاء ملون (Teal)
```

**كبير (L):**
```
القطر: 20 سم
الطول: 50 سم
للمنتج: معدات طويلة، مجموعات
التكلفة: 3,500 دينار
الإغلاق: غطاء + حزام
```

#### **لماذا الزبون راح يصور؟**
```
📸 اللحظة 1: يستلم الأنبوب
"شكله مثل lab equipment!" 🧪

📸 اللحظة 2: يفتح الغطاء
صوت "POP" = satisfying!

📸 اللحظة 3: يشد المنتج من الداخل
"طلع ملفوف مثل scroll!" 📜
```

#### **التنفيذ:**
- **اشتري أنابيب كرتون جاهزة:** متوفرة في سوق الشورجة (للملصقات والبوسترات)
- **عدّل الحجم:** اطلب مقاسات مخصصة
- **الزينة:** لصق ملصق AQUAVO + غطاء ملون

### **3️⃣ شكل المثلث (Triangular Prism) - "الهرم الحديث"** 🔺

```
الشكل:
  /\
 /  \
/____\

لماذا؟
- حاد وجريء (edgy)
- يقف على القاعدة = stable
- زوايا حادة = Instagram angles! 📐
- يبدو "premium"
```

#### **المقاسات الثلاثة:**

**صغير (S):**
```

الارتفاع: 12 سم
للمنتج: علب طعام، عينات
التكلفة: 1,000 دينار
```

**متوسط (M):**
```
القاعدة: 15×15 سم
الارتفاع: 20 سم
للمنتج: فلاتر، إضاءة
التكلفة: 1,800 دينار
```

**كبير (L):**
```
القاعدة: 30×30 سم
الارتفاع: 45 سم
للمنتج: معدات متعددة
التكلفة: 4,000 دينار
```

#### **لماذا الزبون راح يصور؟**
```
📸 اللحظة 1: يشوف الشكل
"مثلث؟! هذا جديد!" 🔺

📸 اللحظة 2: يصوره من الجوانب
"كل زاوية تطلع حلوة!"

📸 اللحظة 3: يفتحه من الأعلى
"ينفتح مثل pyramid!" 🔓
```

#### **التنفيذ:**
- **اصنعه محلياً:** مصنع كرتون يسوي قالب مثلث (one-time: 150,000 د)
- **DIY:** قص كرتون بباترون مثلث وثنيه
- **طباعة:** اطبع "خطوط هندسية" على الجوانب = يبدو أكثر حداثة
