```
"Tank setup is stunning! 😍 How's the nitrogen cycle stability with this bio-load? Room temp dechlorinated water for changes?"
```

### **للأسماك النادرة:**
```
"Never seen this species before! What's the care level? And what's your water parameter routine?"
```

### **للنباتات:**
```
"Plant growth is incredible! 🌱 Root tabs or liquid ferts? And how's your CO2/nutrient balance?"
```

### **للصيانة:**
```
"Love the real maintenance work! Important: always use tank water for filter cleaning, not tap - preserves beneficial bacteria."
```

### **للمشاكل:**
```
"Had the same issue! Check your nitrogen cycle first - ammonia spike can cause this. Reducing light to 6 hours helped me too."
```

### **للإضاءة:**
```
"Lighting is perfect! What fixture and photoperiod? Too much = algae bloom."
```

### **للفلاتر:**
```
"What's your filter media setup? Bio-media quality makes or breaks the nitrogen cycle."
```

### **للأكل:**
```
"What's the feeding routine? Pro tip: avoid cheap colored pellets - artificial dyes damage fish liver over time."
```

## ⚠️ **تحذيرات احترافية (ضيفها بتعليقاتك):**

### **الأخطاء الكارثية اللي لازم تنبه عليها:**

1. **ماء الحنفية الحار:**
```
"Quick tip: never use hot tap water for changes — kills beneficial bacteria in seconds! Always room temp dechlorinated 💧"
```

2. **الأكل الملون الرخيص:**
```
"Colors look great! Avoid cheap dyed pellets — they destroy liver function. Natural protein only! 🐟"
```

3. **تجاهل الدورة النتروجينية:**
```
"Tank looks good, but most critical question: nitrogen cycle STABILITY? Not just cycled - stable? That's the foundation of every thriving aquarium."
```

4. **غسل الفلتر بماء الحنفية:**
```
"Filter maintenance tip: always clean media with tank water, not tap - chlorine kills your beneficial bacteria colony!"
```

5. **الإضاءة المفرطة:**
```
"Lighting setup is nice, but watch the photoperiod - more than 8-10 hours = algae explosion. Balance is key!"
```
