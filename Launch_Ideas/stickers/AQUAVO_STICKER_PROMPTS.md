## 1. ملصق "قبل ما تشغّل — 3 خطوات تنقذ منتجك"

**الفكرة:** كل منتج له ملصق مختلف فيه 3 خطوات حرجة قبل أول استخدام. هذا ينقذ المنتج من التلف.

**للسخان:**
```
قبل ما تشغّل السخان — 3 خطوات

1. غمّره بالماء بالكامل — تشغيله بدون ماء يحرقه خلال 30 ثانية
2. انتظر 20 دقيقة بعد ما تحطه بالماء قبل التشغيل
3. ضعه بزاوية 45 درجة وليس عمودي — يوزع الحرارة أفضل بـ 3 مرات

AQUAVO — نحميك قبل ما تحتاج حماية
```

**للمضخة:**
```
قبل ما تشغّل المضخة — 3 خطوات

1. اغسل الإسفنجة بماء الحوض فقط — ماء الحنفية يقتل البكتيريا النافعة
2. تأكد من عدم وجود هواء محبوس — حرّك المضخة تحت الماء
3. الصوت العالي = هواء عالق أو حصى داخل — ليس عيب بالمنتج

AQUAVO — الخبرة قبل المنتج
```

**للسيفون:**
```
قبل ما تستخدم السيفون — 3 أشياء لازم تعرفها

1. لا تغيّر أكثر من 30% من الماء مرة وحدة — يصدم الأسماك
2. حرّك الحصى بالسيفون ببطء — تحته أوساخ ما تشوفها بالعين
3. الماء الجديد لازم نفس درجة حرارة الحوض — فرق 3 درجات يمرّض السمك

AQUAVO — نعلّمك قبل ما نبيعك
```

### البروموت:
```
Design a vertical rectangular premium sticker (60mm x 90mm) for AQUAVO aquarium brand. White background with deep navy (#0A1F3B) top header bar containing Arabic text "قبل ما تشغّل السخان" in white. Below: 3 numbered steps in clean Arabic typography with small minimalist icons next to each step (1. water drop icon, 2. clock icon, 3. 45-degree angle icon). Bottom: thin teal line separator, then "AQUAVO — نحميك قبل ما تحتاج حماية" in small text. Clean, instructional, professional medical-pamphlet aesthetic. No emoji.

## 2. ملصق "المسطرة" (Ruler Sticker)

- لون تيل على أبيض
- في أحد الأطراف: "AQUAVO Measure" صغير

Minimal, functional, precision tool aesthetic. The ruler must look accurate and usable. No emoji. Print-ready.

## 3. ملصق "ألوان اختبار الماء" (Water Test Color Chart)

**الفكرة:** مرجع ألوان لشرائط اختبار الماء. بدل ما يفتح الزبون موبايله كل مرة، يقارن اللون مباشرة بالملصق. يلصقه بجانب الحوض.

**المحتوى:**
```
مرجع ألوان اختبار الماء — AQUAVO

pH:
[أصفر] 6.0 | [أخضر فاتح] 6.5 | [أخضر] 7.0 | [أزرق فاتح] 7.5 | [أزرق] 8.0
← المثالي: 6.5 - 7.5 ←

أمونيا (NH3):
[أصفر] 0 آمن | [أخضر فاتح] 0.25 خطر | [أخضر] 0.5 طوارئ | [أزرق أخضر] 1.0+ كارثة

نترايت (NO2):
[أزرق فاتح] 0 آمن | [بنفسجي فاتح] 0.25 خطر | [بنفسجي] 0.5 طوارئ | [بنفسجي غامق] 1.0+ كارثة
```

### البروموت:
```
Design a rectangular reference card sticker (85mm x 55mm) for AQUAVO aquarium brand. White background. Title in navy: "مرجع ألوان اختبار الماء" with AQUAVO logo. Three rows of color gradient swatches: Row 1 "pH" showing yellow to blue gradient with values 6.0-8.0. Row 2 "Ammonia" showing yellow to green with danger levels. Row 3 "Nitrite" showing blue to purple with danger levels. Arabic labels. Green checkmark on safe values, red X on dangerous values. Clean scientific chart aesthetic. No emoji. Print-ready.
