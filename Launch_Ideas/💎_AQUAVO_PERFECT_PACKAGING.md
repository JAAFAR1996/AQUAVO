## 📦 **الطبقة الخارجية (المفاجأة الأولى):**

```
الشكل:
- صندوق كرتون قوي (أسود أو بني غامق)
- شريط لاصق holographic (يلمع بألوان قوس قزح!)
- ملصق صغير فقط: "AQUAVO 🐟" (ذهبي لامع)

التكلفة:
- صندوق: 800 دينار
- شريط holographic: 300 دينار
- ملصق ذهبي: 200 دينار
= 1,300 دينار
```

**الانطباع:** بسيط من بره... لكن الشريط اللامع = فضول!

## 💎 **الطبقة الداخلية (الانفجار البصري!):**

### **عند فتح الصندوق:**

```
💥 BOOM! انفجار ألوان!

المحتويات:
1. Tissue paper بألوان نيون (وردي فاقع + أزرق فيروزي)
2. Confetti على شكل سمك (يتطاير عند الفتح!)
3. المنتج ملفوف بقماش مخملي (أزرق غامق)
4. بطاقة ذهبية holographic: "مرحباً بك في AQUAVO ✨"
5. رائحة خفيفة (ocean breeze scent card)
```

### **التكلفة:**
```
- Tissue paper نيون (طبقتين): 400 دينار
- Confetti سمك: 300 دينار
- قماش مخملي صغير: 500 دينار
- بطاقة holographic: 300 دينار
- Scent card: 200 دينار
= 1,700 دينار
```

**💰 التكلفة الكلية: 3,000 دينار/صندوق**

### **1. الشريط Holographic** 🌈
```
المادة: شريط لاصق يتغير لونه حسب الضوء
الألوان: قوس قزح (rainbow effect)
التأثير: يلمع بالكاميرا = Instagram gold!
```

### **2. Confetti السمك** 🐟
```
الشكل: قصاصات ورق على شكل سمك صغير
الألوان: فيروزي + ذهبي
التأثير: عند فتح الصندوق = يتطاير! (dramatic!)
```

### **3. القماش المخملي** 💙
```
الملمس: ناعم جداً (velvet feel)
اللون: أزرق غامق (Deep Teal)
التأثير: الزبون يحس بالـ luxury!
```

### **4. البطاقة الذهبية** ✨
```
المادة: ورق holographic ذهبي
النص: "مرحباً [اسم الزبون]
       رحلتك مع AQUAVO تبدأ الآن 🌊
       - فريق AQUAVO"
التأثير: شخصي + فاخر
```

### **5. الرائحة** 👃
```
النوع: Scent card (كرت صغير معطر)
الرائحة: Ocean breeze (نسيم البحر)
التأثير: تجربة حسية كاملة!
```
