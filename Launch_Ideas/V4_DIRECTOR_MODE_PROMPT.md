# 📋 الخطوة 1: انسخ هذا الـ Prompt

```
أنت مخرج سينمائي. مهمتك إنشاء شبكة storyboard واحدة 3×3 (9 لوحات).

الصورة المرجعية: سمكة ذهبية كرتونية 3D بأسلوب Pixar (مرفقة).

القصة في 30 ثانية:
سمكة تثبت أن ذاكرتها ليست 3 ثواني - تحل متاهة تعلمتها قبل 3 أشهر.

---

أنشئ صورة واحدة 16:9 تحتوي على شبكة 3×3 كالتالي:

الصف الأول (من اليسار):
1. HOOK: يد تضرب زجاج الحوض، السمكة مصدومة، نص "MYTH X"
2. التحدي: السمكة عند مدخل المتاهة، Timer "00:00"
3. الخطأ: السمكة اصطدمت بحائط مسدود، وجه حزين

الصف الثاني:
4. التوقف: السمكة متجمدة تفكر، عيون مغلقة
5. التذكر: السمكة عيونها تلمع! لحظة "آها!"
6. السرعة: السمكة تسبح بسرعة، motion blur

الصف الثالث:
7. الوصول: السمكة تأكل الطعام، Timer "00:12"
8. العاطفة: اليد ترجع بلطف، السمكة تنظر بحكمة
9. CTA: السمكة تغمز للكاميرا، نص "@aquavo"

القواعد:
- نفس السمكة في كل اللوحات (من الصورة المرجعية)
- نفس ستايل Pixar 3D
- كل لوحة مرقمة (1-9)
- خلفية موحدة = حوض سمك زجاجي مع متاهة شفافة
```

RULES:
- SAME fish character in ALL 9 panels (match reference)
- Same 3D Pixar cartoon style throughout
