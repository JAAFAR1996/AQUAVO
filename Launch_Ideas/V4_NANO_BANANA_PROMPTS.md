## 🎬 KF1: HOOK - الصدمة (0-0.5s)

### الرسم المرجعي:
```
┌─────────────────────────────────────────────────┐
│                                                 │
│  👋💥━━━►                                       │
│  HAND                                           │
│  HITS        ╔═════════════════════════════╗    │
│  GLASS       ║                             ║    │
│              ║           ·🐟😱             ║    │
│              ║         (shocked)           ║    │
│              ║                             ║    │
│              ║     [MAZE BEHIND]           ║    │
│              ╚═════════════════════════════╝    │
│                                                 │
│       ╔══════════════════════════╗              │
│       ║  ❌ MYTH: "3 SECONDS"   ║              │
│       ╚══════════════════════════╝              │
└─────────────────────────────────────────────────┘
```

### Prompt (Natural Language):
```
Create a dramatic scene in 3D Pixar animation style. Show a glass aquarium from the front view. A human hand is hitting the aquarium glass from outside, creating visible water ripples and a splash effect inside the water.

Inside the aquarium, there is a small cute golden goldfish. The fish should be very small, about 5% of the frame size. The fish is jumping backward in shock with a scared surprised expression - eyes wide open, mouth open in an O shape.

Behind the fish, there is a large transparent acrylic maze structure that fills about 70% of the aquarium interior. The maze has multiple pathways.

Overlay a big red stamp that says "MYTH" with a red X crossing it out. Below it, text saying "3 SECONDS" also crossed out.

The lighting is dramatic with a slight blue tone. Crystal clear water with visible caustic light reflections.

Aspect ratio 9:16 vertical (portrait mode for mobile). High resolution 4K quality.

Do not include: watermarks, text errors, extra fingers on the hand.
```

Soft top lighting with caustic reflections on the aquarium floor. Tiny bubbles rising. Crystal clear water.
