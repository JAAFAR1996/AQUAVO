# 🐛 قائمة المشاكل — AQUAVO QA Audit

**التاريخ:** 2026-02-21 | **المجموع:** 2 حرج + 8 مهم + 6 تحسين = **16 مشكلة**

---

## 🔴 P0 — حرج (يمنع الإطلاق)

### BUG-01: أسعار 90 منتج = 0 د.ع
- **المسار:** `/products` + `/api/products`
- **التفاصيل:** 90 من 116 منتج بسعر 0. فقط 26 لديها variants بأسعار.
- **التأثير:** المتجر لا يعمل تجارياً — لا يمكن بيع شيء.
- **الإصلاح:** تسعير يدوي في قاعدة البيانات عبر Drizzle أو لوحة الإدارة.

### BUG-02: تسريب passwordHash في `/api/user`
- **المسار:** `GET /api/user`
- **التفاصيل:** الاستجابة تحتوي على `passwordHash` للمستخدم المسجل.
- **التأثير:** ثغرة أمنية حرجة — يمكن للمهاجم قراءة الـ hash.
- **الإصلاح:** إضافة `sanitizeUser()` في route `/api/user` كما تم في `/api/admin`.
- **الملف:** `server/routes/users.ts` (أو ما يعادله)

## 🟡 P1 — مهم

### BUG-03: قسم آراء العملاء (Testimonials) مفقود
- **المسار:** الصفحة الرئيسية `/`
- **التفاصيل:** لا يوجد قسم testimonials رغم وجوده في التصميم.

### BUG-04: Smart Reminders → 500 Error
- **المسار:** `GET /api/products/predicted-needs`
- **التفاصيل:** زر الإشعارات 🔔 ينتقل لـ `#predicted-needs` لكن الـ API يعطي 500.
- **الإصلاح:** فحص endpoint `predicted-needs` في الـ backend.

### BUG-05: `/cart` → 404
- **المسار:** `https://aquavo.vercel.app/cart`
- **التفاصيل:** لا توجد صفحة سلة مستقلة — السلة sidebar فقط.
- **التأثير:** لا يمكن مشاركة رابط السلة.

### BUG-06: Cart Sidebar ناقص الميزات
- **المسار:** الـ sidebar الجانبي للسلة
- **التفاصيل:** لا يوجد أزرار (+/-) لتغيير الكمية ولا حقل كوبون خصم.

### BUG-07: `/admin-login` → 404
- **المسار:** `https://aquavo.vercel.app/admin-login`
- **التفاصيل:** الرابط غير موجود. الأدمن يدخل من `/login` العادي.

### BUG-08: `/returns` → 404
- **المسار:** `https://aquavo.vercel.app/returns`
- **التفاصيل:** صفحة سياسة الإرجاع غير موجودة (بينما FAQ + Shipping + Privacy + Terms تعمل).

### BUG-09: الشات بوت لا يعرف أسعار المنتجات
- **المسار:** الشات بوت (شريمب)
- **التفاصيل:** عند سؤال "كم سعر فلتر SOBO؟" يرد أنه لا يملك بيانات.
- **الإصلاح:** ربط الشات بوت بـ product catalog API.

### BUG-10: API Endpoints مفقودة
- **المسارات:** `GET /api/system/health` و `GET /api/categories`
- **التفاصيل:** كلاهما يعطي 404.

## 🟢 P2 — تحسين

### BUG-11: Scroll Progress Bar شبه شفاف
- **المسار:** الصفحة الرئيسية
- **التفاصيل:** شريط التقدم موجود لكن بالكاد يُرى.

### BUG-12: 3 منتجات بدون صور
- **التفاصيل:** SOBO + 2 YEE بدون صور.

### BUG-13: بعض Variant names = `undefined`
- **التفاصيل:** أسماء بعض المتغيرات تظهر كـ undefined.

### BUG-14: صفحة العروض فارغة
- **المسار:** `/deals`
- **التفاصيل:** "0 منتجات" — لا توجد عروض نشطة.

### BUG-15: FCP = 4,504ms
- **التفاصيل:** First Contentful Paint بطيء (المعيار < 1,800ms).
- **الإصلاح:** تحسين SSR أو lazy loading.

### BUG-16: زر بدون aria-label
- **التفاصيل:** 1 من 64 زر بدون accessible label.
