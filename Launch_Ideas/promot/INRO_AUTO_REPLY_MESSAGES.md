# 💎 AQUAVO_DM_STRATEGY (The Triage System)
> **الفلسفة:** أنت مو "بياع لزكة" تركض ورا الزبون. أنت **استشاري مشغول** الناس تنتظر دورها عندك.
> **النبرة:** مباشرة، محترفة، مساعدة لكن حازمة.
> **اللهجة:** عراقية طبيعية (مو فصحى رسمية).

---

## 📋 القواعد الأساسية

| القاعدة | التطبيق |
|:---|:---|
| **لا تذكر السعر أولاً** | حوّل سؤال السعر إلى نقاش فني |
| **لا تبيع بدون تأهيل** | تأكد إن حوض الزبون جاهز قبل ما تبيعه شي |
| **اسأل قبل ما تجاوب** | "دزلي فيديو" أقوى من "جرب هالمنتج" |
| **لا ترد فوراً** | 5-15 دقيقة تأخير = انت مشغول وخبير (مو بطال) |
| **التشخيص قبل الوصفة** | ممنوع توصي بمنتج بدون ما تشوف الحوض |

---

## 1. 🚪 رسالة الترحيب (First Touch)
**المحفز (Trigger):** رسالة جديدة / "Get Started" / أول تواصل

**الرد:**
```
اهلا بك في AQUAVO 💎
النظام يعمل الآن. لضمان أفضل نصيحة، الرجاء اختر سبب المراسلة:

1️⃣ عندي سمكة مريضة / مشكلة بالحوض
   (أرسل فيديو للحوض فوراً — بدون فلاش).

2️⃣ استشارة لتصميم حوض جديد (Zero to Hero).

3️⃣ استفسار عن منتج معين.

⚠️ ملاحظة: لا نقوم ببيع الكائنات الحية بدون التأكد من جاهزية حوضك.
```

---

## 2. 🔬 مسار التشخيص (Option 1 — Diagnosis Flow)
**المستخدم يقول:** "عندي سمكة دتموت" / "المي وصخ" / "مشكلة بالحوض"

### الخطوة 1 — جمع المعلومات:
```
دزلي فيديو واضح للحوض (بدون فلاش) يركز على:
١. حركة السمكة.
٢. سطح الماء.
٣. نوع الفلتر.

واكتبلي:
- شكد صارلك مما مشغل الحوض؟
- شكد حجمه (بالـ لتر)؟
- آخر مرة بدلت المي؟

بدون هاي المعلومات، اي علاج انطيكياه يعتبر "تخمين" وممكن يضر السمك.
```

### الخطوة 2 — بعد استلام الفيديو:
```
شكراً. خلّني أراجع الفيديو..

[بعد 3-5 دقائق]

طيب، من الفيديو أشوف [الملاحظة].

التشخيص المبدئي: [اسم المشكلة].

البروتوكول:
١. [خطوة أولى — عادةً تغيير ماء]
٢. [خطوة ثانية — علاج أو تعديل]
٣. [خطوة ثالثة — متابعة]

هل تحتاج المواد؟ عندنا [المنتج] متوفر.
```

### الخطوة 3 — إذا ما أرسل فيديو:
```
ممتاز بس اسهل شي نساعدك بيه لو نشوف فيديو.
بدون فيديو، أكدر أنطيك نصائح عامة بس مو تشخيص دقيق.

ارسلّي فيديو ١٥ ثانية وراح أساعدك بأسرع وقت 👍
```

---

## 3. 🏗️ مسار التصميم (Option 2 — Zero to Hero)
**المستخدم يقول:** "أريد أبدأ حوض" / "شلون أبدأ؟"

### الخطوة 1 — التأهيل (Qualification):
```
ممتاز! قبل ما نبدأ، جاوبني على ٣ أسئلة:

١. الميزانية الكاملة (حوض + معدات + أسماك)؟
   💰 تحت 50$ / 50-150$ / 150-300$ / فوك 300$

٢. المكان المتاح — شكد المساحة (عرض × عمق)؟

٣. الهدف — شنو تبي بالضبط؟
   🐟 أسماك ملونة بس (Community Tank)
   🌿 حوض مزروع طبيعي (Planted Tank)
   🦐 جمبري وحلزونات (Shrimp Tank)

بدون هاي المعلومات ما أكدر أنصحك بالشي الصح.
```

### الخطوة 2 — التوصية:
```
بناءً على إجاباتك، أنصحك بالباكج التالي:

📦 باكج [الاسم]:
- حوض: [النوع] — [الحجم]
- فلتر: [النوع]
- إضاءة: [النوع]
- تربة: [النوع]

💰 الإجمالي: [السعر] د.ع.

⚠️ ملاحظة مهمة: الحوض يحتاج يشتغل "فارغ" لمدة ٢-٣ أسابيع قبل ما تضيف أسماك (دورة النيتروجين). هذي مو اختيارية — هذي قانون.

تريد أبدأ أجهزلك الطلب؟
```

---

## 4. 💰 انحراف صدمة السعر (Price Shock Deflection)
**المستخدم يقول:** "بيش هذا؟" / "السعر؟" / "شكد؟" (بدون سياق)

### الرد:
```
سعره [XX,XXX] د.ع.

بس قبل ما تطلبه — هذا المنتج يحتاج حوض [مواصفات معينة] حتى يشتغل صح.

حوضك جاهز؟ لو تحب أساعدك تختار الأنسب الك؟
```
> **(هنا حوّلت سؤال السعر إلى نقاش فني. الزبون يحس إنك تهتم بنجاح تجربته، مو بس تبيعه وتمشي.)**

### إذا قال "غالي":
```
أفهمك. خلّني أوضحلك الفرق:

المنتج الرخيص: يشتغل ٣-٦ شهور، يحتاج استبدال، ممكن يسرب مواد ضارة.
هذا المنتج: يشتغل ٢-٣ سنوات، كفالة، مواد آمنة 100%.

بالحساب — هذا أرخص على المدى الطويل.
بس إذا الميزانية محدودة، عندي بديل بـ [سعر أقل] يسويلك نفس الشغل.
```

## 5. 🔄 المتابعة (Follow-up — بعد البيع)
**المحفز:** بعد 3 أيام من الشراء

```
مرحبا! كيف صار الوضع مع [المنتج]؟
إذا واجهت أي مشكلة بالتركيب أو الإعداد، دزلي فيديو وأساعدك.

ملاحظة: لا تنسى [نصيحة متعلقة بالمنتج].
```

**المحفز:** بعد أسبوع

```
أسبوع! كيف الحوض؟
لو تبي — دزلي صورة للحوض وأنطيك تقييم مجاني + نصائح تحسين 💎
```

## 6. 🚫 الردود على المواقف الصعبة

### "ليش سمكتي ماتت بعد ما شريت من عندكم؟"
```
أعتذرلك على الخسارة، هذا شي مو سهل.

خلّيني أشخّص السبب عشان ما يتكرر:
- متى وصلت السمكة؟
- كيف أقلمتها؟ (حطيتها بالماي مباشرة لو سويت أقلمة تدريجية؟)
- شكد حرارة حوضك وقتها؟
- هل فحصت الأمونيا والنتريت؟

أغلب الحالات سببها "صدمة الأقلمة" أو "حوض غير مجهز".
راح أساعدك تتجنب هالشي بالمرة الجاية.
```

### "عندكم توصيل؟"
```
نعم، نوصل لكل المحافظات 🚚

داخل بغداد: [السعر] — توصيل خلال ٢٤ ساعة.
باقي المحافظات: [السعر] — توصيل خلال ٢-٤ أيام.

الأسماك الحية نوصلها بعلب حرارية مخصصة لضمان وصولها بصحة ممتازة.

شنو تحتاج؟
```

### "أريد أرجع المنتج"
```
طبعاً، سياسة الإرجاع عندنا واضحة:

✅ المنتج يرجع خلال ٧ أيام إذا كان بحالته الأصلية.
❌ الكائنات الحية لا ترجع (لصحة وسلامة الحيوان).

دزلي صورة للمنتج + رقم الطلب وأبدأ الإجراء.
```

## 📊 مقاييس النجاح (KPIs)

| المقياس | الهدف |
|:---|:---|
| **وقت الرد الأول** | < 15 دقيقة (ساعات العمل) |
| **معدل التحويل (DM → شراء)** | > 25% |
| **معدل طلب الفيديو** | > 60% يرسلون فيديو |
| **معدل المتابعة بعد البيع** | 100% (آلي) |
| **تقييم رضا العميل** | > 4.5/5 |

---

> **الخلاصة:** أنت مو بياع. أنت **طبيب أحواض**.
> الزبون ما يشتري "منتج" — يشتري **ثقة بخبير**.
> كل محادثة = فرصة لبناء هالثقة.
