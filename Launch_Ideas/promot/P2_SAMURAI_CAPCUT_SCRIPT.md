## 1. الخطوط المعتمدة

### الخط الرئيسي: Cairo Bold
- **لماذا:** أوضح خط عربي جيومتري على الشاشات الصغيرة، يدعم كل الأوزان، مقروئية عالية جداً
- **الاستخدام:** العناوين الرئيسية + Hook + CTA
- **الوزن:** Bold (700) أو ExtraBold (800)
- **التحميل:** [Google Fonts — Cairo](https://fonts.google.com/specimen/Cairo)

### الخط الثانوي: Tajawal Regular
- **لماذا:** جيومتري نظيف، حديث، أخف من Cairo — مثالي للمواصفات
- **الاستخدام:** النصوص الثانوية + المواصفات التقنية
- **الوزن:** Regular (400) أو Medium (500)
- **التحميل:** [Google Fonts — Tajawal](https://fonts.google.com/specimen/Tajawal)

### خط البراند: Inter Medium
- **لماذا:** للنص الإنجليزي فقط (AQUAVO + aquavoiq.com)
- **الوزن:** Medium (500)

> [!IMPORTANT]
> **قاعدة RTL:** كل النصوص العربية → محاذاة يمين. اكتب النص في Notes أولاً ثم الصقه في CapCut.

## 7. تعليمات CapCut

### الكليبات
```
VID-01 (0:00-0:04): العدو — السخان القبيح
VID-02 (0:04-0:15): الكشف — الساموراي من الظلام
VID-03 (0:15-0:22): الاختفاء — يندمج بالحوض
VID-04 (0:22-0:30): الكشف النهائي
```

### الانتقالات
```
VID-01 → VID-02: Hard Cut (قطع حاد)
VID-02 → VID-03: Cross Dissolve 0.5ث
VID-03 → VID-04: Cross Dissolve 0.3ث
```

### لكل نص
```
1. اكتب النص في Notes → الصق في CapCut
2. اختر الخط والحجم من الجدول
3. ضبط اللون
4. محاذاة يمين (عربي) / وسط (إنجليزي)
5. Drop Shadow: Distance 3, Blur 6, #000000, 80%
6. Stroke: 2px, #000000, 60%
7. ضبط Y% من الجدول
8. Animation In + Out
9. ضبط التوقيت بالمللي ثانية
```

### Engagement Loop
```
آخر 0.5ث من VID-04 (حوض مثالي)
← قطع حاد ←
أول فريم VID-01 (سخان قبيح)
```

### التصدير
```

```
