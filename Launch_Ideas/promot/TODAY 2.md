> 2. Suno **ما يفهم timestamps** (مثل "at 8 seconds") → **استخدم meta tags** مثل `[Intro]` `[Build]` `[Drop]`
> 3. **3-7 وصّافات** كحد أقصى — كثرة التعليمات تربك الذكاء الاصطناعي
> 4. **فصل Style عن Structure** — Style في خانة الـ Style، والتراكيب بالـ Lyrics
> 5. استخدم **lowercase bpm** (مثلاً `85bpm` مو `85 BPM`) — أثبت أنه أدق

### 📋 كيف تستخدم البروموتات:

| الخطوة | الفعل |
|:--|:--|
| 1 | افتح **suno.com** → اختر **Custom Mode** |
| 2 | فعّل **Instrumental** ✅ (مهم! بدون كلمات) |
| 3 | انسخ **"حقل Style"** بخانة **Style of Music** |
| 4 | انسخ **"حقل Structure"** بخانة **Lyrics** (يكون فاضي عادةً — نحط بس meta tags) |
| 5 | اضغط **Generate** |
| 6 | **قص المقطع** حسب طول الستوري (15-20 ثانية) |

### 🎹 بروموت #1 — ستوري 1: "هل تستخدم سخان؟ ❄️" (فضول + برد غامض)

> 🎯 **الجو المطلوب:** إحساس بارد غامض → سؤال معلّق
> ⏱️ **مصمم لـ 15 ثانية** — لوب بارد هادئ

**حقل Style of Music** (انسخه كامل):
```
cold ambient drone, frozen piano notes, subtle wind texture, icy reverb, mysterious atmospheric, winter aquatic, sparse and haunting, instrumental, 65bpm, key of A minor
```

**حقل Lyrics** (انسخه — meta tags فقط):
```
[Intro: cold wind drone with distant frozen piano notes, sparse and eerie, ice texture]
```

> 🧠 **ليش مناسب لـ 15 ثانية؟**
> - **قسم واحد `[Intro]` لوب:** Suno يولّد لوب بارد — **أي 15 ثانية تقصها تشتغل!**
> - **A minor:** مقام الغموض والبرد — يطرح السؤال بصوت الموسيقى
> - **wind texture:** صوت رياح خفيفة = يعزز الإحساس بالبرد
> - **بعد التوليد:** قص أي 15 ثانية — كلها نفس الجو البارد

### 🎹 بروموت #2 — ستوري 2: "الأسماك ذوات الدم البارد 🔬" (تعليمي علمي)

> 🎯 **الجو المطلوب:** هدوء تعليمي أنيق — حلقة ناعمة
> ⏱️ **مصمم لـ 15 ثانية** — لوب هادئ يشتغل بأي مقطع

**حقل Style of Music** (انسخه كامل):
```
calm looping piano, soft Rhodes keys, lo-fi ambient loop, subtle water droplets, clean and premium, modern tutorial aesthetic, no percussion, repeating gentle melody, instrumental, 70bpm, key of C major
```

**حقل Lyrics** (انسخه — meta tags فقط):
```
[Verse: gentle repeating Rhodes melody with water droplets, clean and spacious, calming loop]
```

> 🧠 **ليش مناسب لـ 15 ثانية؟**
> - **repeating melody:** اللحن يتكرر كل ~4 ثواني = مثالي للقراءة
> - **C Major + 70bpm:** أمثل مزيج للقراءة الهادئة — مثبت بأبحاث UX
> - **water droplets:** AQUAVO sonic branding مدمج

### 🎹 بروموت #3 — ستوري 3: "كويز الحرارة 🌡️" (تشويق + كشف)

> 🎯 **الجو المطلوب:** ترقب → كشف الإجابة
> ⏱️ **مصمم لـ 15 ثانية**

**حقل Style of Music** (انسخه كامل):
```
suspenseful quiz show stinger, ticking clock rhythm, building tension synth, sudden warm resolution, game show reveal moment, instrumental, 100bpm, key of G minor
```

**حقل Lyrics** (انسخه — meta tags فقط):
```
[Intro: ticking clock with building tension synth pad]

[Drop: warm bright reveal chord splash, triumphant and satisfying]
```

> 🧠 **ليش مناسب لـ 15 ثانية؟**
> - **قسمين فقط:** `[Intro]→[Drop]` = توتر + كشف — مثالي لـ Quiz!
> - **ticking clock:** يخلق عد تنازلي نفسي — يشد الانتباه
> - **reveal moment:** لحظة الكشف = dopamine hit — يخلّي المتابع ينتظر الكويز القادم

### 🎹 بروموت #4 — ستوري 4: "عد تنازلي للحلقة 3 🪞" (حماس + ترقب)

> 🎯 **الجو المطلوب:** طاقة حماسية → ترقب
> ⏱️ **مصمم لـ 15 ثانية**

**حقل Style of Music** (انسخه كامل):
```
exciting teaser trailer, playful synth melody, upbeat energy, comedic undertone, bright and curious, building anticipation, instrumental, 120bpm, key of D major
```

**حقل Lyrics** (انسخه — meta tags فقط):
```
[Intro: playful curious synth melody, bouncy and light, building excitement]
```

> 🧠 **ليش مناسب لـ 15 ثانية؟**
> - **playful + curious:** يعكس شخصية السمكة المغرورة بالحلقة 3 (تحارب انعكاسها!)
> - **D Major:** مقام "المرح والتفاؤل" — يخلي المتابع يبتسم ويترقب
> - **120bpm:** إيقاع سريع حماسي = الطاقة تنقل للمتابع
